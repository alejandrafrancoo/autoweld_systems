Automatización Industrial de Soldadura

Sistema automatizado mediante UR10e, ESP32-S3 y MQTT para optimizar procesos de soldadura industrial.

¿En qué consiste el proyecto?

Este proyecto consiste en la automatización de una celda de soldadura para travesaños del esqueleto de un coche.

El sistema utiliza robots industriales UR10e y Yaskawa AR1440, sensores de seguridad, MQTT para comunicaciones y RoboDK para la simulación industrial.

Además, se utiliza una ESP32-S3 para controlar sensores y gestionar eventos de seguridad, permitiendo una integración completa entre hardware y software industrial.

Gracias a esta automatización se consigue reducir tiempos, disminuir errores de producción y mejorar la seguridad del operario.
